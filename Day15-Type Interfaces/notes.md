## interface

_Blueprint of an object structure. It defines property names and property types and method structure and object rules._

_Interface describes how an object should look_

_In typescript an interface is a syntactical contract that defines the shape of an object. It specifies the required properties and methods an object must have, ensuring consistency and enabling static-type checking during development._
_Interface does not create object, this defines only rules and structures._
_Type alias will work for primitive or non-primitive both but interface will only work with object reference._
