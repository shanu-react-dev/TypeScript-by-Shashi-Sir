## What is Typescript configurations

using command `tsc --init` we can create one configuration file.

### tsconfig.json file

_Think of it as the brain of your typescript project. Its presenece in a directory tells the computer that this folder is the root of a typescript project. Essentially it acts as an instruction manual for the typescript compiler, defining exactly how your code should be checked and converted into JavaScript_

_A tsconfig.json file is the configuration file for typescript _
