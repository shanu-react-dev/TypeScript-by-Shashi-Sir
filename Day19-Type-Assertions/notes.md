## Type Assertions

_It is also called as Type Casting it is a way by which you can change or convert one type to another type onlyy in compile time it is not runt time._

_It is used to tell the TypeScript "I know the type better than you."_

_It is a compile time only feature not runtime feature._

_It does not convert the value just changing the type_

_It just tell typescript how to treat the value._
